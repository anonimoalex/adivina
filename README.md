# 🎮 Adivina el Númer

Este es un sencillo juego de consola hecho en Python donde el jugador debe adivinar un número secreto generado al azar entre 1 y 100.


- El juego elige un número aleatorio entre 1 y 100.
- El jugador intenta adivinar el número.
- El juego indica si el número ingresado es demasiado alto o bajo.
- El juego termina cuando se adivina correctamente.

## ▶️ Cómo jugar

```bash
python adivina_el_numero.py
